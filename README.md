# 🛡️ Overwatch 2 - Concept Landing Page

Un sitio web promocional e interactivo inspirado en la estética oficial de Blizzard previa al lanzamiento de **Overwatch 2**. Desarrollado como proyecto integrador para el curso de **Desarrollo Web en Coderhouse**.

🌐 **Demo en vivo:** [https://ivantuama98.github.io/PF-Tuama/](https://ivantuama98.github.io/PF-Tuama/)

---

**📌 Características del Sitio

- 🎮 **Estética & UI Gaming:** Diseño oscuro con acentos dorados/naranjas característicos de la interfaz del juego.
- 📱 **Diseño 100% Responsive:** Adaptado fluido para móviles, tablets y monitores de escritorio.
- 🧱 **Secciones Principales:**
  - Hero Section con llamado a la acción (*Pre-order / News*).
  - Presentación de Héroes y roles (*Tank, Damage, Support*).
  - Novedades del modo PvP 5v5 y mapas.
  - Formulario de contacto / suscripción a noticias.
- 🎨 **Estilizado Avanzado:** Maquetación modular utilizando SASS y componentes de Bootstrap 5.

---

🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica de contenidos.
- **CSS3 & SASS (SCSS):** Uso de variables, mixins, nesting y arquitectura modular para mantener estilos limpios.
- **Bootstrap 5:** Sistema de grillas y componentes responsivos.
- **Git & GitHub:** Control de versiones y despliegue continuo en **GitHub Pages**.
